Mastering Android Camera2 API

Learn the Android Camera2 API from the foundations of smartphone camera hardware to advanced capabilities and metadata.

📄️제1장: Android Camera2에 오신 것을 환영합니다

Android Camera2가 중요한 이유, CameraX와의 차이점, 그리고 이 시리즈에서 다룰 내용에 대해 알아봅니다.

📄️제 2장: 스마트폰 카메라 이해하기

Camera2를 배우기 전에 렌즈, 센서, ISP 및 사진 생성 과정을 포함한 스마트폰 카메라 구성 요소를 알아보세요.

📄️3장: 현대 스마트폰 카메라는 무엇을 할 수 있나요?

인물 모드, HDR, 야간 모드, RAW 촬영 등 현대 스마트폰 카메라의 놀라운 기능들을 알아보세요.

📄️4장: 휴대폰 카메라 탐색하기

Android Camera Parameters 앱을 사용하여 카메라 ID, 해상도, FPS, 하드웨어 레벨, RAW 지원 등 기기의 카메라 기능을 탐색해 보세요.

📄️5장: Camera2 시작하기

카메라를 열거하고 특성에 접근할 수 있게 해주는 Android Camera2 API의 진입점인 CameraManager에 대해 알아봅니다.

📄️6장: 카메라 목록화

Android 기기에서 사용 가능한 모든 카메라를 찾아 목록으로 표시하는 첫 번째 Camera2 프로그램을 작성해 보세요.

📄️7장: CameraCharacteristics 이해하기

CameraCharacteristics를 탐색하여 렌즈 방향, 하드웨어 레벨, 센서 크기 및 기타 중요한 카메라 기능에 대해 알아봅니다.

📄️8장: 첫 번째 카메라 열기

CameraManager를 사용하여 CameraDevice를 여는 방법과 상태 콜백으로 카메라 라이프사이클을 처리하는 방법을 알아보세요.

📄️9장: 카메라 미리보기 표시하기

Camera2에서 TextureView, Surface, CameraCaptureSession을 사용하여 카메라 미리보기를 표시하는 방법을 알아보세요.

📄️10장: ImageReader로 사진 촬영하기

Camera2에서 이미지 데이터를 수신하는 핵심 구성 요소인 ImageReader를 사용하여 정지 사진을 촬영하는 방법을 알아봅니다.

📄️11장: RAW 촬영과 CaptureRequest

RAW 이미지를 촬영하는 방법을 배우고 고급 카메라 제어를 위한 CaptureRequest와 CaptureResult를 이해합니다.

📄️12장: 수동 카메라 - ISO와 노출

Camera2로 전문 사진 촬영을 위해 ISO와 노출 시간을 수동으로 제어하는 방법을 알아보세요.

📄️제13장: 수동 카메라 - 초점과 화이트 밸런스

Camera2로 전문 사진 촬영을 위해 초점 거리와 화이트 밸런스를 수동으로 제어하는 방법을 알아보세요.

📄️14장: 전문가 기능 - 고속 비디오

Camera2에서 고속 비디오를 캡처하고 멀티 카메라 설정을 다루는 방법을 알아봅니다.

📄️제15장: CameraCharacteristics 백과사전

가장 중요한 Camera2 특성에 대한 종합 가이드 — 의미, 존재 이유, 사용 방법을 포함합니다.
