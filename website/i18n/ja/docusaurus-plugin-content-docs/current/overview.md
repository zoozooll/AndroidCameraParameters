# アプリの概要

このページでは、アプリケーションのダッシュボードと主要機能について詳しく説明します。

![アプリの概要](/img/camera_params_feature_graph.png)

## ダッシュボードの構成要素

### 1. ナビゲーションと選択
- **メニュードロワー**: 左上のメニューアイコンから、プライバシーポリシー、アプリの評価、および「アプリについて」の情報にアクセスできます。
- **カメラの選択**: カメラ名またはIDバッジ（例：「0」）をタップしてドロップダウンを開き、使用可能なレンズ（背面、前面、超広角など）を切り替えます。
- **ボトムナビゲーション**: **Overview**（概要）、**Categories**（カテゴリ）、**Raw JSON**（生JSON）、**Favorites**（お気に入り）をシームレスに切り替えます。

### 2. サマリーカード
上部のサマリーカードには、最も重要な情報が表示されます。
- **Hardware Level**: Camera2 APIのサポートレベル（LEGACY、LIMITED、FULL、またはLEVEL_3）。これにより、レンズの全体的な機能が決まります。

### 3. 主要機能グリッド
プロフェッショナル向け機能のステータスを即座に確認できる視覚的なグリッドです。
- **解像度とセンサーサイズ**: センサーの物理的な特性。
- **最大ビデオFPS**: ピーク時のフレームレート機能。
- **RAWサポート**: センサーが非圧縮データを出力できるかどうかを示します。
- **OIS (光学式手ぶれ補正)**: 物理的なレンズ手ぶれ補正の有無。
- **マニュアルコントロール**: マニュアル露出とマニュアルフォーカスのサポートステータス。
- **プロセッシング**: HDR、顔検出、赤目軽減のサポート状況。

### 4. カテゴリ別パラメータ (Categoriesタブ)
論理的なグループに整理されたCameraCharacteristicsの全リストを探索できます。
- **センサー**: 解像度、物理サイズ、感度範囲。
- **レンズ**: 焦点距離、絞り、手ぶれ補正モード。
- **AE/AF/AWB**: 露出、フォーカス、ホワイトバランスの詳細な制御モード。
- **検索**: 統合された検索バーを使用して、特定のAPIキーや値を素早く見つけることができます。
