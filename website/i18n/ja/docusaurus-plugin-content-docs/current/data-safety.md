# データセーフティガイド

このドキュメントでは、Android Camera Parametersアプリケーションのデータ収集とプライバシー慣行の概要を説明します。

## 概要

Android Camera Parametersは、「プライバシー第一」のアプローチで設計されています。診断ツールとして、機能するためにハードウェア情報にアクセスする必要がありますが、個人データを収集または送信することはありません。

## 権限

### カメラ権限 (`android.permission.CAMERA`)
- **要件**: CameraManagerにアクセスし、CameraCharacteristicsを取得するために必要です。
- **使用法**: アプリはハードウェアのメタデータのみを読み取ります。ユーザーの明示的な操作（画像キャプチャテストが追加された場合の将来のバージョンなど）なしに、ビデオを録画したり写真を撮影したりすることはありません。

## データ収集

- **個人情報**: アプリは名前、メールアドレス、電話番号、その他の個人識別情報を**収集しません**。
- **位置データ**: アプリはGPSやネットワークの場所に**アクセスしません**。
- **ハードウェアメタデータ**: アプリはカメラレンズの技術仕様（解像度、焦点距離、サポートされているモード）を読み取ります。このデータは、ユーザーが明示的に「Export JSON」機能を使用して共有しない限り、デバイス内に留まります。

## データ共有

アプリケーションはデータを第三者と**共有しません**。コアアプリには、トラッキングSDK（Firebase AnalyticsやFacebook SDKなど）は統合されていません。

## ユーザーによる制御

- **JSONエクスポート**: ユーザーは生のカメラパラメータJSONをコピーまたは共有することを選択できます。これは完全にユーザー主導で行われます。
- **権限**: Androidのシステム設定からいつでもカメラ権限を取り消すことができますが、権限がないとアプリはカメラの詳細を表示できなくなります。
