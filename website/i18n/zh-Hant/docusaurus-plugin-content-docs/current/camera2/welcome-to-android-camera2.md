在控制攝像頭之前，我們需要瞭解攝像頭系統。

## 簡介

如今，幾乎每部智慧型手機都有強大的攝像頭系統。現代手機可以：

- 拍攝具有專業外觀的照片
- 錄製 4K 和 8K 影片
- 建立人像效果
- 在極暗光線下拍攝
- 拍攝慢動作影片
- 生成深度資訊
- 將多個攝像頭組合在一起

但是，當你打開預設的攝像頭應用程式時，你只會看到一個簡單的介面：一個快門按鈕、一個變焦控制和幾種拍攝模式。

在這個簡單的介面背後是一個極其複雜的系統。攝像頭應用程式與硬體元件、圖像處理器和 Android 框架通信，以生成每一幀。

作為 Android 開發者，我們可能希望構建超越預設攝像頭應用程式的應用程式，例如：

- 手動攝影應用程式
- 攝像頭測試工具
- 電腦視覺應用程式
- 3D 掃描應用程式
- 專業錄影程式
- 攝像頭功能分析器

要構建這些應用程式，我們需要瞭解 Android Camera2 API。

## 什麼是 Android Camera2？

Android Camera2 是 Google 在 Android 5.0（API 級別 21）中引入的現代攝像頭框架。它取代了原始的 Android Camera API。

舊的 Camera API 是為了一個更簡單的世界設計的：一個攝像頭、基礎照片拍攝和簡單的影片錄製。自那時起，智慧型手機攝像頭發生了巨大變化。現代設備可能包含多個後置攝像頭、廣角鏡頭、長焦鏡頭、深度感測器和外置攝像頭。

它們還支援進階功能：

- 手動曝光和對焦
- RAW 圖像拍攝
- 高速影片
- HDR 處理
- 光學防手震

Camera2 的建立是為了讓開發者能夠更深入地控制攝像頭硬體。

## Camera2 與 CameraX

Camera2 和 CameraX 解決不同的問題。

### CameraX

CameraX 是一個更高層級的庫，旨在簡化常見的攝像頭任務，包括：

- 顯示預覽
- 拍照
- 錄製影片
- 處理設備相容性

大多數應用程式應該從 CameraX 開始。

### Camera2

Camera2 是較低層級的框架。它讓開發者可以直接存取攝像頭功能，包括感測器資訊、曝光設定、對焦控制、攝像頭元數據、硬體功能和 RAW 支援。

Camera2 更複雜，但它提供了更多的控制權。

| | CameraX | Camera2 |
| --- | --- | --- |
| 層級 | 進階庫 | 低階 API |
| 難度 | 較容易 | 更複雜 |
| 控制 | 有限 | 廣泛 |
| 適用場景 | 普通攝像頭應用 | 進階攝像頭應用程式 |

本系列教學重點介紹 Camera2，因為瞭解它可以幫助我們瞭解 Android 攝像頭究竟是如何運作的。

## 為什麼要學習 Camera2？

你可能會問：*既然已經有了 CameraX，為什麼還要學習 Camera2？*

### 瞭解設備的真實能力

每部 Android 手機都是不同的。一台設備可能支援 RAW 拍攝、4K 60 fps 影片和手動控制；而另一台可能不支援。Camera2 允許應用程式發現這些功能。

### 構建專業攝像頭應用程式

需要進階攝像頭功能的應用程式通常需要 Camera2。範例包括專業攝像頭應用、科學成像應用、AR 應用程式、電腦視覺系統和影片製作工具。

### 瞭解智慧型手機攝影

許多現代攝像頭功能都基於透過 Camera2 公開的概念：

- 曝光
- ISO
- 對焦
- 白平衡
- HDR
- 多攝像頭

學習 Camera2 還可以教你智慧型手機攝像頭是如何運作的。

## 結合 Android Camera Parameters 學習

閱讀文件很有用，但當你能看到來自真實手機的真實數據時，攝像頭功能會更容易理解。在整個系列中，我們將使用 [Android Camera Parameters](/) 來探索實際的攝像頭資訊。

## 在我們開始編碼之前

Camera2 並不難，不是因為 API 設計得不好。它之所以難，是因為現代攝像頭功能極其強大。

智慧型手機攝像頭不再僅僅是一個捕獲圖像的感測器。它是一個完整的成像系統，涉及：

- 硬體
- 韌體
- ISP 處理
- Android 框架
- 應用程式軟體

Camera2 向開發者公開了這種複雜性。我們的目標是在本系列中逐步瞭解它。
