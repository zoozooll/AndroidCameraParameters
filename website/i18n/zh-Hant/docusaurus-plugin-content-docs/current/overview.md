# 應用概覽

本頁面詳細介紹了應用程式的儀表板和關鍵功能。

![應用概覽](/img/camera_params_feature_graph.png)

## 儀表板組件

### 1. 導覽與選擇
- **選單抽屜**：透過左上角的選單圖示存取隱私權政策、應用程式評分和關於資訊。
- **相機選擇**：點擊相機名稱或 ID 標記（例如 "0"）開啟下拉式選單，在可用鏡頭（後置、前置、超廣角等）之間切換。
- **底部導覽**：在**概覽 (Overview)**、**分類 (Categories)**、**原生 JSON (Raw JSON)** 和**收藏 (Favorites)** 之間無縫切換。

### 2. 摘要卡
頂部的摘要卡提供了最關鍵的資訊：
- **硬體層級**：Camera2 API 支援層級（LEGACY、LIMITED、FULL 或 LEVEL_3）。這決定了鏡頭的整體能力。

### 3. 關鍵特性網格
直觀的網格提供專業級特性的即時狀態：
- **解析度與感光元件尺寸**：感光元件的物理特性。
- **最大影片 FPS**：峰值幀率能力。
- **RAW 支援**：指示感光元件是否可以輸出未壓縮數據。
- **OIS (光學防手震)**：物理鏡頭防手震可用性。
- **手動控制**：手動曝光和手動對焦支援的狀態。
- **處理**：HDR、面部偵測和紅眼消除的支援情況。

### 4. 分類參數 (分類索引標籤)
探索按邏輯分組組織的完整 CameraCharacteristics 列表：
- **感光元件 (Sensor)**：解析度、物理尺寸、靈敏度範圍。
- **鏡頭 (Lens)**：焦距、光圈、防手震模式。
- **AE/AF/AWB**：曝光、對焦和白平衡的詳細控制模式。
- **搜尋**：使用整合搜尋欄快速查找特定的 API 鍵或值。
