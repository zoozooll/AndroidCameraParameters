# 數據安全指南

本文件概述了 Android Camera Parameters 應用程式的數據收集和隱私慣例。

## 概覽

Android Camera Parameters 採用「隱私優先」的方法設計。作為一款診斷工具，它需要存取硬體資訊才能運作，但不會收集或傳輸個人數據。

## 權限

### 相機權限 (`android.permission.CAMERA`)
- **要求**：存取 `CameraManager` 並檢索 `CameraCharacteristics` 所必需。
- **用法**：應用僅讀取硬體元數據。它**不會**在沒有用戶明確操作的情況下錄製影片或拍攝照片（例如，如果將來版本中添加了影像採集測試）。

## 數據收集

- **個人資訊**：應用**不收集**姓名、電子郵件地址、電話號碼或任何其他個人識別碼。
- **位置數據**：應用**不存取**您的 GPS 或網路位置。
- **硬體元數據**：應用讀取相機鏡頭的技術規格（解析度、焦距、支援模式）。除非您明確使用「導出 JSON」功能進行共享，否則這些數據將保留在您的設備上。

## 數據共享

該應用程式**不與第三方共享**任何數據。核心應用中未整合任何追蹤 SDK（如 Firebase Analytics 或 Facebook SDK）。

## 用戶控制

- **JSON 導出**：用戶可以選擇複製或共享原始相機參數 JSON。這完全由用戶發起。
- **權限**：您可以隨時透過 Android 系統設定撤銷相機權限，但如果沒有該權限，應用將無法顯示相機詳細資訊。
