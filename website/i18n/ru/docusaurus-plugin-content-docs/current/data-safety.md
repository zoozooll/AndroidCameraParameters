# Руководство по безопасности данных

В этом документе описаны методы сбора данных и обеспечения конфиденциальности в приложении Android Camera Parameters.

## Обзор

Приложение Android Camera Parameters разработано с подходом «Конфиденциальность прежде всего». Как диагностический инструмент, оно требует доступа к информации об оборудовании для работы, но не собирает и не передает личные данные.

## Разрешения

### Разрешение на использование камеры (`android.permission.CAMERA`)
- **Требование**: необходимо для доступа к `CameraManager` и получения `CameraCharacteristics`.
- **Использование**: приложение считывает только метаданные оборудования. Оно **не записывает** видео и **не делает** фотографии без явного действия пользователя (например, если в будущих версиях будет добавлено тестирование захвата изображений).

## Сбор данных

- **Личная информация**: приложение **не собирает** имена, адреса электронной почты, номера телефонов или любые другие личные идентификаторы.
- **Данные о местоположении**: приложение **не имеет доступа** к вашему GPS или сетевому местоположению.
- **Метаданные оборудования**: приложение считывает технические характеристики объективов вашей камеры (разрешение, фокусное расстояние, поддерживаемые режимы). Эти данные остаются на вашем устройстве, если вы явно не воспользуетесь функцией «Экспорт JSON» для их передачи.

## Обмен данными

Приложение **не передает** никакие данные третьим лицам. В ядро приложения не интегрированы никакие SDK для отслеживания (такие как Firebase Analytics или Facebook SDK).

## Управление пользователем

- **Экспорт JSON**: пользователи могут скопировать или поделиться исходным JSON-файлом параметров камеры. Это действие инициируется исключительно пользователем.
- **Разрешения**: вы можете отозвать разрешение на использование камеры в любое время через настройки системы Android, однако без него приложение не сможет отображать сведения о камере.
