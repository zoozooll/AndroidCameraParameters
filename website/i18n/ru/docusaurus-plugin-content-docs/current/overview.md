# Обзор приложения

Эта страница содержит подробный разбор панели управления приложением и его основных функций.

![Обзор приложения](/img/camera_params_feature_graph.png)

## Компоненты панели управления

### 1. Навигация и выбор
- **Боковое меню**: доступ к Политике конфиденциальности, оценке приложения и информации «О программе» через иконку меню в левом верхнем углу.
- **Выбор камеры**: нажмите на название камеры или значок ID (например, «0»), чтобы открыть выпадающий список и переключиться между доступными объективами (основной, фронтальный, сверхширокоугольный и т. д.).
- **Нижняя навигация**: плавное переключение между вкладками **Обзор** (Overview), **Категории** (Categories), **Raw JSON** и **Избранное** (Favorites).

### 2. Карточка сводки
Карточка сводки (Summary Card) в верхней части экрана содержит самую важную информацию:
- **Уровень оборудования** (Hardware Level): уровень поддержки Camera2 API (LEGACY, LIMITED, FULL или LEVEL_3). Это определяет общие возможности объектива.

### 3. Сетка ключевых функций
Визуальная сетка, обеспечивающая мгновенный статус функций профессионального уровня:
- **Разрешение и размер сенсора**: физические характеристики сенсора.
- **Макс. FPS видео**: пиковые возможности частоты кадров.
- **Поддержка RAW**: указывает, может ли сенсор выводить несжатые данные.
- **OIS (Оптическая стабилизация изображения)**: наличие физической стабилизации объектива.
- **Ручное управление**: статус поддержки ручной экспозиции и ручной фокусировки.
- **Обработка**: поддержка HDR, обнаружение лиц и уменьшение эффекта «красных глаз».

### 4. Категоризированные параметры (вкладка Categories)
Изучите полный список характеристик камеры (CameraCharacteristics), организованных в логические группы:
- **Сенсор** (Sensor): разрешение, физический размер, диапазоны чувствительности.
- **Объектив** (Lens): фокусное расстояние, диафрагма, режимы стабилизации.
- **AE/AF/AWB**: подробные режимы управления экспозицией, фокусировкой и балансом белого.
- **Поиск**: используйте встроенную строку поиска, чтобы быстро найти определенные ключи API или значения.
