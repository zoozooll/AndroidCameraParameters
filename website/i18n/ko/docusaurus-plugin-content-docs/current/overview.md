# 앱 개요

이 페이지는 애플리케이션의 대시보드와 주요 기능에 대한 자세한 분석을 제공합니다.

![앱 개요](/img/camera_params_feature_graph.png)

## 대시보드 구성 요소

### 1. 탐색 및 선택
- **메뉴 드로어**: 왼쪽 상단의 메뉴 아이콘을 통해 개인정보 처리방침, 앱 평가 및 정보에 액세스합니다.
- **카메라 선택**: 카메라 이름 또는 ID 배지(예: "0")를 누르면 드롭다운이 열리고 사용 가능한 렌즈(후면, 전면, 초광각 등) 간에 전환할 수 있습니다.
- **하단 탐색**: **개요**, **카테고리**, **원시 JSON**, **즐겨찾기** 사이를 원활하게 전환합니다.

### 2. 요약 카드
상단의 요약 카드는 가장 중요한 정보를 제공합니다.
- **하드웨어 레벨**: Camera2 API 지원 레벨(LEGACY, LIMITED, FULL 또는 LEVEL_3). 이는 렌즈의 전반적인 기능을 결정합니다.

### 3. 주요 기능 그리드
전문가 수준 기능의 실시간 상태를 제공하는 시각적 그리드입니다.
- **해상도 및 센서 크기**: 센서의 물리적 특성입니다.
- **최대 비디오 FPS**: 최고 프레임 속도 기능입니다.
- **RAW 지원**: 센서가 압축되지 않은 데이터를 출력할 수 있는지 여부를 나타냅니다.
- **OIS (광학 이미지 흔들림 보정)**: 물리적 렌즈 안정화 가용성입니다.
- **수동 제어**: 수동 노출 및 수동 초점 지원 상태입니다.
- **처리**: HDR, 얼굴 감지 및 적목 현상 제거 지원 여부입니다.

### 4. 카테고리별 파라미터 (카테고리 탭)
논리적 그룹으로 정리된 CameraCharacteristics의 전체 목록을 탐색합니다.
- **센서**: 해상도, 물리적 크기, 감도 범위.
- **렌즈**: 초점 거리, 조리개, 안정화 모드.
- **AE/AF/AWB**: 노출, 초점 및 화이트 밸런스에 대한 상세 제어 모드.
- **검색**: 통합 검색 바를 사용하여 특정 API 키 또는 값을 빠르게 찾을 수 있습니다.
