# 데이터 안전 가이드

이 문서는 Android Camera Parameters 애플리케이션의 데이터 수집 및 개인정보 보호 관행을 설명합니다.

## 개요

Android Camera Parameters는 "개인정보 우선" 원칙으로 설계되었습니다. 진단 도구로서 기능을 위해 하드웨어 정보에 액세스해야 하지만, 개인 데이터를 수집하거나 전송하지 않습니다.

## 권한

### 카메라 권한 (`android.permission.CAMERA`)
- **요구 사항**: `CameraManager`에 액세스하고 `CameraCharacteristics`를 검색하는 데 필요합니다.
- **사용**: 앱은 하드웨어 메타데이터만 읽습니다. 사용자의 명시적인 작업(예: 향후 버전에서 이미지 캡처 테스트가 추가되는 경우) 없이는 비디오를 녹화하거나 사진을 촬영하지 **않습니다**.

## 데이터 수집

- **개인 정보**: 앱은 이름, 이메일 주소, 전화번호 또는 기타 개인 식별자를 **수집하지 않습니다**.
- **위치 데이터**: 앱은 사용자의 GPS 또는 네트워크 위치에 **액세스하지 않습니다**.
- **하드웨어 메타데이터**: 앱은 카메라 렌즈의 기술 사양(해상도, 초점 거리, 지원 모드)을 읽습니다. 이 데이터는 사용자가 명시적으로 "JSON 내보내기" 기능을 사용하여 공유하지 않는 한 장치에 그대로 유지됩니다.

## 데이터 공유

애플리케이션은 어떤 데이터도 제3자와 **공유하지 않습니다**. 핵심 앱에는 통합된 추적 SDK(예: Firebase Analytics 또는 Facebook SDK)가 없습니다.

## 사용자 제어

- **JSON 내보내기**: 사용자는 원시 카메라 파라미터 JSON을 복사하거나 공유하도록 선택할 수 있습니다. 이는 전적으로 사용자가 시작합니다.
- **권한**: 안드로이드 시스템 설정을 통해 언제든지 카메라 권한을 취소할 수 있지만, 권한 없이는 앱에서 카메라 세부 정보를 표시할 수 없습니다.
