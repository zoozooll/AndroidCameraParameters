在控制摄像头之前，我们需要了解摄像头系统。

## 简介

如今，几乎每部智能手机都有强大的摄像头系统。现代手机可以：

- 拍摄具有专业外观的照片
- 录制 4K 和 8K 视频
- 创建人像效果
- 在极暗光线下拍摄
- 拍摄慢动作视频
- 生成深度信息
- 将多个摄像头组合在一起

但是，当你打开默认的摄像头应用时，你只会看到一个简单的界面：一个快门按钮、一个变焦控制和几种拍摄模式。

在这个简单的界面背后是一个极其复杂的系统。摄像头应用与硬件组件、图像处理器和 Android 框架通信，以生成每一帧。

作为 Android 开发者，我们可能希望构建超越默认摄像头应用的应用程序，例如：

- 手动摄影应用程序
- 摄像头测试工具
- 计算机视觉应用程序
- 3D 扫描应用程序
- 专业视频录制器
- 摄像头功能分析器

要构建这些应用程序，我们需要了解 Android Camera2 API。

## 什么是 Android Camera2？

Android Camera2 是 Google 在 Android 5.0（API 级别 21）中引入的现代摄像头框架。它取代了原始的 Android Camera API。

旧的 Camera API 是为一个更简单的世界设计的：一个摄像头、基础照片拍摄和简单的视频录制。自那时起，智能手机摄像头发生了巨大变化。现代设备可能包含多个后置摄像头、广角镜头、长焦镜头、深度传感器和外置摄像头。

它们还支持高级功能：

- 手动曝光和对焦
- RAW 图像拍摄
- 高速视频
- HDR 处理
- 光学防抖

Camera2 的创建是为了让开发者能够更深入地控制摄像头硬件。

## Camera2 与 CameraX

Camera2 和 CameraX 解决不同的问题。

### CameraX

CameraX 是一个更高级别的库，旨在简化常见的摄像头任务，包括：

- 显示预览
- 拍照
- 录制视频
- 处理设备兼容性

大多数应用程序应该从 CameraX 开始。

### Camera2

Camera2 是较低级别的框架。它让开发者可以直接访问摄像头功能，包括传感器信息、曝光设置、对焦控制、摄像头元数据、硬件功能和 RAW 支持。

Camera2 更复杂，但它提供了更多的控制权。

| | CameraX | Camera2 |
| --- | --- | --- |
| 级别 | 高级库 | 低级 API |
| 难度 | 较容易 | 更复杂 |
| 控制 | 有限 | 广泛 |
| 适用场景 | 普通摄像头应用 | 高级摄像头应用程序 |

本系列教程重点介绍 Camera2，因为了解它可以帮助我们了解 Android 摄像头究竟是如何工作的。

## 为什么要学习 Camera2？

你可能会问：*既然已经有了 CameraX，为什么还要学习 Camera2？*

### 了解设备的真实能力

每部 Android 手机都是不同的。一台设备可能支持 RAW 拍摄、4K 60 fps 视频和手动控制；而另一台可能不支持。Camera2 允许应用程序发现这些功能。

### 构建专业摄像头应用程序

需要高级摄像头功能的应用程序通常需要 Camera2。示例包括专业摄像头应用、科学成像应用、AR 应用程序、计算机视觉系统和视频制作工具。

### 了解智能手机摄影

许多现代摄像头功能都基于通过 Camera2 公开的概念：

- 曝光
- ISO
- 对焦
- 白平衡
- HDR
- 多摄像头

学习 Camera2 还可以教你智能手机摄像头是如何工作的。

## 结合 Android Camera Parameters 学习

阅读文档很有用，但当你能看到来自真实手机的真实数据时，摄像头功能会更容易理解。在整个系列中，我们将使用 [Android Camera Parameters](/) 来探索实际的摄像头信息。

## 在我们开始编码之前

Camera2 并不难，不是因为 API 设计得不好。它之所以难，是因为现代摄像头功能极其强大。

智能手机摄像头不再仅仅是一个捕获图像的传感器。它是一个完整的成像系统，涉及：

- 硬件
- 固件
- ISP 处理
- Android 框架
- 应用程序软件

Camera2 向开发者公开了这种复杂性。我们的目标是在本系列中逐步了解它。

Android Camera2 是在 Android 上构建高级摄像头应用程序的基础。它提供了对普通摄像头应用程序中隐藏的摄像头功能和控制的直接访问。
