在学习 Camera2 之前，让我们先了解一下你要控制的摄像头。

## 简介

看看你智能手机的背面。

你可能会看到一个摄像头。

或者两个。

或者三个甚至五个摄像头镜头。

现代智能手机摄像头功能强大。有些可以录制 8K 视频。有些可以拍摄出色的夜景照片。还有些可以捕捉 RAW 图像用于专业编辑。

但是你有没有想过按下快门按钮后实际上发生了什么？

摄像头只是简单地拍照吗？

远不止如此。

拍摄一张照片需要多个硬件组件在短短几分之一秒内协同工作。理解这些组件将使学习 Camera2 变得更加容易。

## 智能手机摄像头不仅仅是一个镜头

很多人认为手机背面的黑色圆圈就是"摄像头"。

实际上，那些圆圈只是镜头。一个完整的智能手机摄像头由几个主要组件组成。

```
光线
│
▼
镜头
│
▼
图像传感器
│
▼
ISP（图像信号处理器）
│
▼
内存
│
▼
Android 摄像头框架
│
▼
你的应用程序
```

每张照片都遵循这个流程。让我们逐一检查每个组件。

## 镜头

镜头是摄像头的第一个部分。它的工作很简单：

> 收集光线并将其聚焦到图像传感器上。

不同的镜头产生不同的图像。例如：

- **广角镜头** — 标准日常摄影
- **超广角镜头** — 捕捉更多的场景
- **长焦镜头** — 使远处的物体看起来更近
- **微距镜头** — 聚焦于几厘米外的物体

每个镜头都有不同的用途。

Camera2 可以告诉我们手机有哪些镜头。在本系列的后面部分，我们将学习 Android 如何识别它们。

## 图像传感器

镜头后面是图像传感器。这是光线变成数字信息的地方。

数百万个微小的像素覆盖在传感器表面。每个像素测量到达它的光量。光线越亮，产生的电信号就越大。

然后摄像头将这些电信号转换为数字值。这就是传感器产生的"原始"图像。

**一个重要事实：** 图像传感器捕获的是光，而不是颜色。我们稍后会解释原因。

### 为什么更大的传感器通常能产生更好的照片

制造商喜欢宣传像素数。你可能见过配备以下像素数的手机：

- 4800 万像素
- 6400 万像素
- 1.08 亿像素
- 2 亿像素

但像素数只是故事的一部分。

想象两个收集雨水的桶。一个较大的桶比较小的桶收集更多的水。

像素的工作原理类似。更大的像素收集更多的光线。更多的光线通常意味着：

- **更低的图像噪点**
- **更好的低光性能**
- **更高的动态范围**

这就是为什么旗舰手机通常比预算手机产生更好的图像，即使它们宣传相似的像素数。

## ISP — 隐藏的英雄

大多数人从未听说过 ISP。ISP 代表 **图像信号处理器**（Image Signal Processor）。它是智能手机中最重要的组件之一。

可以把它想象成摄像头的照片编辑器。ISP 接收原始传感器数据并执行许多处理步骤，包括：

- **去马赛克** — 从单个像素重建颜色
- **降噪** — 减少照片中的颗粒感
- **白平衡** — 校正色温
- **曝光调整** — 使图像变亮或变暗
- **锐化** — 增强细节
- **HDR 合并** — 组合多次曝光
- **色彩校正** — 调整颜色使其看起来自然
- **镜头畸变校正** — 修复桶形或枕形畸变

没有 ISP，照片通常会看起来很暗、充满噪点且不自然。

在许多情况下，图像质量不仅取决于摄像头传感器本身，还取决于 ISP。

## 为什么 RAW 图像看起来很奇怪

早些时候我们说传感器捕获的是光，而不是颜色。这怎么可能呢？

每个传感器像素只能测量入射光的强度。为了记录颜色，大多数传感器使用 **拜耳色彩滤镜阵列**（Bayer Color Filter Array）。

每个像素只记录一种颜色：

- **红色**
- **绿色**
- **蓝色**

ISP 结合相邻像素来重建全彩色图像。这个过程称为 **去马赛克**。

RAW 图像是在大部分处理发生之前捕获的。这就是为什么 RAW 照片通常比 JPEG 图像看起来更平淡、更暗、色彩更少。专业编辑软件稍后会执行剩余的处理。

## 多摄像头正成为标准

现在许多手机都包含多个摄像头。例如：

| 摄像头 | 典型用途 |
| --- | --- |
| **广角** | 日常摄影 |
| **超广角** | 风景和建筑 |
| **长焦** | 变焦和人像 |
| **微距** | 特写摄影 |
| **深度** | 深度估计 |

每个摄像头都有自己的：

- **镜头**
- **传感器**
- **特性**
- **功能**

Android Camera2 将每个摄像头视为单独的设备。在后面的章节中，当我们探索摄像头 ID 时，我们会看到这一点。

## 照片是如何创建的

现在让我们把所有内容放在一起。当你按下快门按钮时：

1. **光线进入镜头**
2. **镜头将光线聚焦到传感器上**
3. **传感器将光线转换为电信号**
4. **ISP 处理原始数据**
5. **Android 接收处理后的图像**
6. **你的应用程序显示或保存结果**

虽然整个过程通常不到一秒钟，但幕后发生了许多复杂的操作。

## Camera2 可以控制什么

并非摄像头流程的每个部分都由 Android 控制。然而，Camera2 允许应用程序影响许多重要设置。例如：

- **曝光** — 传感器收集光线的时间长度
- **ISO** — 传感器的灵敏度
- **对焦** — 摄像头对焦的位置
- **白平衡** — 色温调整
- **闪光灯** — 控制闪光灯
- **变焦** — 数码变焦和光学变焦
- **帧率** — 视频帧率
- **图像格式** — JPEG、RAW、YUV
- **输出分辨率** — 图像尺寸

在整个系列中，我们将学习这些设置如何影响图像质量。

## 使用 Android Camera Parameters 探索

在编写任何代码之前，尝试探索你自己的手机。打开 Android Camera Parameters 并查找：

- **摄像头 ID** — Android 如何识别每个摄像头
- **镜头朝向** — 前置、后置或外置
- **传感器尺寸** — 物理尺寸
- **可用焦距** — 不同的镜头
- **硬件支持级别** — LEGACY、LIMITED、FULL 或 LEVEL_3
- **最大数码变焦** — 变焦能力
- **支持的输出尺寸** — 可用分辨率

如果其中一些术语不熟悉，请不要担心。到本书结束时，你将理解每一个术语。

## 总结

智能手机摄像头远不止是一个镜头。它是一个复杂的成像系统，由镜头、传感器、图像处理器、内存和软件共同工作来生成每张照片。

Camera2 API 为开发者提供了对这个系统许多部分的访问权限，但首先理解硬件会使软件学习变得更加容易。

现在你知道智能手机摄像头如何创建图像了，你已经准备好发现为什么不同的 Android 设备会暴露不同的摄像头功能。
