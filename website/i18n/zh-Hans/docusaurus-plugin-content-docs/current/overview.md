# 应用概览

本页面详细介绍了应用程序的仪表板和关键功能。

![应用概览](/img/camera_params_feature_graph.png)

## 仪表板组件

### 1. 导航与选择
- **菜单抽屉**：通过左上角的菜单图标访问隐私政策、应用评分和关于信息。
- **相机选择**：点击相机名称或 ID 徽章（例如 "0"）打开下拉菜单，在可用镜头（后置、前置、超广角等）之间切换。
- **底部导航**：在**概览 (Overview)**、**分类 (Categories)**、**原生 JSON (Raw JSON)** 和**收藏 (Favorites)** 之间无缝切换。

### 2. 摘要卡
顶部的摘要卡提供了最关键的信息：
- **硬件级别**：Camera2 API 支持级别（LEGACY、LIMITED、FULL 或 LEVEL_3）。这决定了镜头的整体能力。

### 3. 关键特性网格
直观的网格提供专业级特性的即时状态：
- **分辨率与传感器尺寸**：传感器的物理特性。
- **最大视频 FPS**：峰值帧率能力。
- **RAW 支持**：指示传感器是否可以输出未压缩数据。
- **OIS (光学防抖)**：物理镜头防抖可用性。
- **手动控制**：手动曝光和手动对焦支持的状态。
- **处理**：HDR、人脸检测和红眼消除的支持情况。

### 4. 分类参数 (分类选项卡)
探索按逻辑分组组织的完整 CameraCharacteristics 列表：
- **传感器 (Sensor)**：分辨率、物理尺寸、灵敏度范围。
- **镜头 (Lens)**：焦距、光圈、防抖模式。
- **AE/AF/AWB**：曝光、对焦和白平衡的详细控制模式。
- **搜索**：使用集成搜索栏快速查找特定的 API 键或值。
