第 1 章：歡迎學習 Android Camera2

在控制攝像頭之前，我們需要瞭解攝像頭系統。

簡介​

如今，幾乎每部智慧型手機都有強大的攝像頭系統。現代手機可以：

  • 拍攝具有專業外觀的照片
  • 錄製 4K 和 8K 影片
  • 建立人像效果
  • 在極暗光線下拍攝
  • 拍攝慢動作影片
  • 生成深度資訊
  • 將多個攝像頭組合在一起

但是，當你打開預設的攝像頭應用程式時，你只會看到一個簡單的介面：一個快門按鈕、一個變焦控制和幾種拍攝模式。

在這個簡單的介面背後是一個極其複雜的系統。攝像頭應用程式與硬體元件、圖像處理器和 Android 框架通信，以生成每一幀。

作為 Android 開發者，我們可能希望構建超越預設攝像頭應用程式的應用程式，例如：

  • 手動攝影應用程式
  • 攝像頭測試工具
  • 電腦視覺應用程式
  • 3D 掃描應用程式
  • 專業錄影程式
  • 攝像頭功能分析器

要構建這些應用程式，我們需要瞭解 Android Camera2 API。

什麼是 Android Camera2？​

Android Camera2 是 Google 在 Android 5.0（API 級別 21）中引入的現代攝像頭框架。它取代了原始的 Android Camera API。

舊的 Camera API 是為了一個更簡單的世界設計的：一個攝像頭、基礎照片拍攝和簡單的影片錄製。自那時起，智慧型手機攝像頭發生了巨大變化。現代設備可能包含多個後置攝像頭、廣角鏡頭、長焦鏡頭、深度感測器和外置攝像頭。

它們還支援進階功能：

  • 手動曝光和對焦
  • RAW 圖像拍攝
  • 高速影片
  • HDR 處理
  • 光學防手震

Camera2 的建立是為了讓開發者能夠更深入地控制攝像頭硬體。

Camera2 與 CameraX​

Camera2 和 CameraX 解決不同的問題。

CameraX​

CameraX 是一個更高層級的庫，旨在簡化常見的攝像頭任務，包括：

  • 顯示預覽
  • 拍照
  • 錄製影片
  • 處理設備相容性

大多數應用程式應該從 CameraX 開始。

Camera2​

Camera2 是較低層級的框架。它讓開發者可以直接存取攝像頭功能，包括感測器資訊、曝光設定、對焦控制、攝像頭元數據、硬體功能和 RAW 支援。

Camera2 更複雜，但它提供了更多的控制權。

CameraXCamera2
層級進階庫低階 API
難度較容易更複雜
控制有限廣泛
適用場景普通攝像頭應用進階攝像頭應用程式

本系列教學重點介紹 Camera2，因為瞭解它可以幫助我們瞭解 Android 攝像頭究竟是如何運作的。

為什麼要學習 Camera2？​

你可能會問：既然已經有了 CameraX，為什麼還要學習 Camera2？

瞭解設備的真實能力​

每部 Android 手機都是不同的。一台設備可能支援 RAW 拍攝、4K 60 fps 影片和手動控制；而另一台可能不支援。Camera2 允許應用程式發現這些功能。

構建專業攝像頭應用程式​

需要進階攝像頭功能的應用程式通常需要 Camera2。範例包括專業攝像頭應用、科學成像應用、AR 應用程式、電腦視覺系統和影片製作工具。

瞭解智慧型手機攝影​

許多現代攝像頭功能都基於透過 Camera2 公開的概念：

  • 曝光
  • ISO
  • 對焦
  • 白平衡
  • HDR
  • 多攝像頭

學習 Camera2 還可以教你智慧型手機攝像頭是如何運作的。

你將在本系列中學到什麼？​

本系列旨在帶你從入門到精通。

第 1 部分：瞭解攝像頭​

你將學習智慧型手機攝像頭的運作原理、攝像頭硬體包含的內容、Android 如何表示攝像頭，以及如何檢查你自己的設備。

第 2 部分：你的第一個 Camera2 應用程式​

你將學習如何尋找和打開攝像頭、建立預覽以及拍攝圖像。

第 3 部分：攝像頭控制​

你將學習曝光、ISO、對焦、白平衡、閃光燈和變焦。

第 4 部分：進階攝像頭功能​

你將學習 RAW 拍攝、高速影片、多攝像頭設備、邏輯和物理攝像頭、攝像頭擴充功能和 HDR 功能。

第 5 部分：攝像頭元數據深度解析​

你將探索重要的 Camera2 參數，包括：

  • android.sensor.info.activeArraySize
  • android.scaler.availableMaxDigitalZoom
  • android.control.aeAvailableModes
  • android.request.availableCapabilities

你不僅會瞭解這些參數的含義，還會瞭解它們存在的原因。

結合 Android Camera Parameters 學習​

閱讀文件很有用，但當你能看到來自真實手機的真實數據時，攝像頭功能會更容易理解。在整個系列中，我們將使用 Android Camera Parameters 來探索實際的攝像頭資訊。

你可以使用該應用發現：

  • 可用攝像頭
  • 支援的解析度
  • 幀率
  • 感測器資訊
  • 手動控制支援
  • RAW 功能
  • 硬體層級

你無需從抽象的例子中學習，而是可以直接調查你自己的設備。

本教學適合誰？​

本系列專為以下人群設計：

  • 想要瞭解基礎 API 之外的攝像頭系統的 Android 開發者。
  • 需要進階攝像頭功能的 攝像頭應用開發者。
  • 需要存取攝像頭幀和元數據的 電腦視覺開發者。
  • 想要瞭解智慧型手機攝像頭究竟如何運作的 好奇開發者。

在我們開始編碼之前​

Camera2 並不難，不是因為 API 設計得不好。它之所以難，是因為現代攝像頭功能極其強大。

智慧型手機攝像頭不再僅僅是一個捕獲圖像的感測器。它是一個完整的成像系統，涉及：

  • 硬體
  • 韌體
  • ISP 處理
  • Android 框架
  • 應用程式軟體

Camera2 向開發者公開了這種複雜性。我們的目標是在本系列中逐步瞭解它。

下一章​

在下一章 瞭解智慧型手機攝像頭硬體 中，我們將暫時離開 Android，探索攝像頭本身。你將學習攝像頭感測器的作用、為什麼大感測器能產生更好的圖像、鏡頭的真實含義、ISP 處理如何運作，以及為什麼兩部像素數相近的手機會拍出完全不同的照片。

一旦你瞭解了硬體，Camera2 的概念就會變得容易得多。

總結​

Android Camera2 是在 Android 上構建進階攝像頭應用程式的基礎。它提供了對普通攝像頭應用程式中隱藏的攝像頭功能和控制的直接存取。

本系列將引導你從瞭解智慧型手機攝像頭到構建專業級的 Camera2 應用程式。讓我們開始這段旅程。
