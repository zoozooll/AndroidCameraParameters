第 2 章：了解智慧型手機相機

在學習 Camera2 之前，讓我們先了解一下你要控制的相機。

簡介​

看看你智慧型手機的背面。

你可能會看到一個相機。

或者兩個。

或者三個甚至五個相機鏡頭。

現代智慧型手機相機功能強大。有些可以錄製 8K 影片。有些可以拍攝出色的夜景照片。還有些可以捕捉 RAW 影像用於專業編輯。

但是你有沒有想過按下快門按鈕後實際上發生了什麼？

相機只是簡單地拍照嗎？

遠不止如此。

拍攝一張照片需要多個硬體組件在短短幾分之一秒內協同工作。理解這些組件將使學習 Camera2 變得更加容易。

智慧型手機相機不僅僅是一個鏡頭​

很多人認為手機背面的黑色圓圈就是"相機"。

實際上，那些圓圈只是鏡頭。一個完整的智慧型手機相機由幾個主要組件組成。

每張照片都遵循這個流程。讓我們逐一檢查每個組件。

鏡頭​

鏡頭是相機的第一個部分。它的工作很簡單：

收集光線並將其聚焦到影像感測器上。

不同的鏡頭產生不同的影像。例如：

  • 廣角鏡頭 — 標準日常攝影
  • 超廣角鏡頭 — 捕捉更多的場景
  • 長焦鏡頭 — 使遠處的物體看起來更近
  • 微距鏡頭 — 聚焦於幾公分外的物體

每個鏡頭都有不同的用途。

Camera2 可以告訴我們手機有哪些鏡頭。在本系列的後面部分，我們將學習 Android 如何識別它們。

影像感測器​

鏡頭後面是影像感測器。這是光線變成數位資訊的地方。

數百萬個微小的像素覆蓋在感測器表面。每個像素測量到達它的光量。光線越亮，產生的電訊號就越大。

然後相機將這些電訊號轉換為數位值。這就是感測器產生的"原始"影像。

一個重要事實： 影像感測器捕獲的是光，而不是顏色。我們稍後會解釋原因。

為什麼更大的感測器通常能產生更好的照片​

製造商喜歡宣傳像素數。你可能見過配備以下像素數的手機：

  • 4800 萬像素
  • 6400 萬像素
  • 1.08 億像素
  • 2 億像素

但像素數只是故事的一部分。

想象兩個收集雨水的桶。一個較大的桶比較小的桶收集更多的水。

像素的工作原理類似。更大的像素收集更多的光線。更多的光線通常意味著：

  • 更低的影像雜訊
  • 更好的低光性能
  • 更高的動態範圍

這就是為什麼旗艦手機通常比預算手機產生更好的影像，即使它們宣傳相似的像素數。

ISP — 隱藏的英雄​

大多數人從未聽說過 ISP。ISP 代表 影像訊號處理器（Image Signal Processor）。它是智慧型手機中最重要的組件之一。

可以把它想象成相機的照片編輯器。ISP 接收原始感測器數據並執行許多處理步驟，包括：

  • 去馬賽克 — 從單個像素重建顏色
  • 降噪 — 減少照片中的顆粒感
  • 白平衡 — 校正色溫
  • 曝光調整 — 使影像變亮或變暗
  • 銳化 — 增強細節
  • HDR 合併 — 組合多次曝光
  • 色彩校正 — 調整顏色使其看起來自然
  • 鏡頭畸變校正 — 修復桶形或枕形畸變

沒有 ISP，照片通常會看起來很暗、充滿雜訊且不自然。

在許多情況下，影像品質不僅取決於相機感測器本身，還取決於 ISP。

為什麼 RAW 影像看起來很奇怪​

早些時候我們說感測器捕獲的是光，而不是顏色。這怎麼可能呢？

每個感測器像素只能測量入射光的強度。為了記錄顏色，大多數感測器使用 拜耳色彩濾鏡陣列（Bayer Color Filter Array）。

每個像素只記錄一種顏色：

  • 紅色
  • 綠色
  • 藍色

ISP 結合相鄰像素來重建全彩色影像。這個過程稱為 去馬賽克。

RAW 影像是在大部分處理發生之前捕獲的。這就是為什麼 RAW 照片通常比 JPEG 影像看起來更平淡、更暗、色彩更少。專業編輯軟體稍後會執行剩餘的處理。

多相機正成為標準​

現在許多手機都包含多個相機。例如：

相機典型用途
廣角日常攝影
超廣角風景和建築
長焦變焦和人像
微距特寫攝影
深度深度估計

每個相機都有自己的：

  • 鏡頭
  • 感測器
  • 特性
  • 功能

Android Camera2 將每個相機視為單獨的設備。在後面的章節中，當我們探索相機 ID 時，我們會看到這一點。

照片是如何建立的​

現在讓我們把所有內容放在一起。當你按下快門按鈕時：

  1. 光線進入鏡頭
  2. 鏡頭將光線聚焦到感測器上
  3. 感測器將光線轉換為電訊號
  4. ISP 處理原始數據
  5. Android 接收處理後的影像
  6. 你的應用程式顯示或保存結果

雖然整個過程通常不到一秒鐘，但幕後發生了許多複雜的操作。

Camera2 可以控制什麼​

並非相機流程的每個部分都由 Android 控制。然而，Camera2 允許應用程式影響許多重要設定。例如：

  • 曝光 — 感測器收集光線的時間長度
  • ISO — 感測器的靈敏度
  • 對焦 — 相機對焦的位置
  • 白平衡 — 色溫調整
  • 閃光燈 — 控制閃光燈
  • 變焦 — 數位變焦和光學變焦
  • 幀率 — 影片幀率
  • 影像格式 — JPEG、RAW、YUV
  • 輸出解析度 — 影像尺寸

在整個系列中，我們將學習這些設定如何影響影像品質。

使用 Android Camera Parameters 探索​

在編寫任何代碼之前，嘗試探索你自己的手機。打開 Android Camera Parameters 並查找：

  • 相機 ID — Android 如何識別每個相機
  • 鏡頭朝向 — 前置、後置或外置
  • 感測器尺寸 — 物理尺寸
  • 可用焦距 — 不同的鏡頭
  • 硬體支援級別 — LEGACY、LIMITED、FULL 或 LEVEL_3
  • 最大數位變焦 — 變焦能力
  • 支援的輸出尺寸 — 可用解析度

如果其中一些術語不熟悉，請不要擔心。到本書結束時，你將理解每一個術語。

下一章​

在下一章中，我們將回答另一個重要問題：

為什麼不同的 Android 手機支援不同的相機功能？

你將學習：

  • 相機硬體級別 — LEGACY、LIMITED、FULL、LEVEL_3
  • 可選功能 — 可能可用或不可用的功能
  • 設備能力 — 查詢相機支援的功能
  • 為什麼有些手機支援 RAW 而其他手機不支援
  • 為什麼 Camera2 在不同設備上的行為不同

這些知識將幫助你理解為什麼 Camera2 應用程式必須始終查詢相機功能，而不是做出假設。

總結​

智慧型手機相機遠不止是一個鏡頭。它是一個複雜的成像系統，由鏡頭、感測器、影像處理器、記憶體和軟體共同工作來生成每張照片。

Camera2 API 為開發者提供了對這個系統許多部分的訪問權限，但首先理解硬體會使軟體學習變得更加容易。

現在你知道智慧型手機相機如何建立影像了，你已經準備好發現為什麼不同的 Android 設備會暴露不同的相機功能。
