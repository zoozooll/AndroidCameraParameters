第四章：探索手機的相機

這是學習變得互動的地方。讓我們探索您手機的相機吧！

簡介​

閱讀有關相機的內容很有幫助，但沒有什麼比看到您自己裝置的真實數據更好的了。這就是 Android Camera Parameters 的用武之地。

本章完全是關於探索的。目前還不需要撰寫程式碼。只需保持好奇心。

安裝 Android Camera Parameters​

如果您還沒安裝，請在您的 Android 裝置上安裝 Android Camera Parameters 應用程式：

  1. 開啟 Google Play 商店
  2. 搜尋「Android Camera Parameters」
  3. 安裝應用程式
  4. 開啟它並授予相機權限

認識介面​

當您開啟應用程式時，會看到數個區段：

總覽畫面​

一目了然顯示基本的相機資訊：

  • 相機 ID
  • 鏡頭方向
  • 硬體等級
  • 感測器尺寸
  • 可用功能

分類畫面​

將相機參數組織成邏輯群組：

  • 相機資訊
  • 感測器
  • 鏡頭
  • 控制
  • 縮放器
  • 閃光燈
  • 以及更多

RAW JSON 畫面​

以原始 JSON 格式顯示完整的 CameraCharacteristics，供進階使用者使用。

開始探索​

讓我們看看您應該留意的關鍵資訊。

相機 ID​

Android 為每個相機指派一個唯一的 ID 編號。尋找：

  • 相機 0 — 通常是後置廣角相機
  • 相機 1 — 可能是前置相機或另一個後置相機
  • 相機 2 — 通常是超廣角或望遠相機
  • 相機 3+ — 額外的相機（微距、景深等）

每個 ID 代表一個獨立的相機裝置，具有自己的特性。

硬體等級​

這是最重要的資訊之一：

等級描述
LEGACY舊裝置，有限的 Camera2 支援
LIMITED基本的 Camera2 功能
FULL完整手動控制、RAW 支援
LEVEL_3進階功能，例如 YUV 再處理

檢查您的手機支援哪種硬體等級。這決定了哪些 Camera2 功能可用。

感測器資訊​

尋找：

  • 感測器尺寸 — 感測器的實體尺寸
  • 作用中陣列尺寸 — 實際用於擷取影像的區域
  • 畫素陣列尺寸 — 感測器上的總畫素數
  • 最大影格持續時間 — 影格之間的最短時間
  • 輸出格式 — JPEG、RAW、YUV 等

解析度選項​

相機支援多種解析度。檢查：

  • 預覽尺寸 — 可用於顯示的解析度
  • 拍照尺寸 — 可用於照片拍攝的解析度
  • 錄影尺寸 — 可用於影片錄製的解析度

注意不同的長寬比：4:3、16:9、1:1。

影格率（FPS）​

尋找：

  • 預覽 FPS 範圍 — 預覽的每秒影格數
  • 拍攝 FPS 範圍 — 靜態拍攝的每秒影格數
  • 高速錄影 — 特殊的高影格率模式

較高的 FPS 意味著更順暢的影片和更靈敏的自動對焦。

RAW 支援​

檢查您的相機是否支援 RAW 拍攝：

  • RAW 格式 — RAW_SENSOR、RAW10、RAW12、RAW16
  • RAW 尺寸 — 可用於 RAW 拍攝的解析度

RAW 支援至少需要 FULL 硬體等級。

閃光燈功能​

尋找：

  • 閃光燈模式 — OFF、ON、AUTO、TORCH
  • 可用模式 — 支援哪些閃光燈功能
  • 閃光燈資訊 — 閃光燈強度和功能

變焦​

檢查：

  • 最大數位變焦 — 您可以數位變焦多少倍
  • 可用焦距 — 不同的鏡頭及其焦距
  • 平順變焦支援 — 變焦是否可以平順調整

對焦模式​

尋找：

  • 可用對焦模式 — AUTO、FIXED、MACRO、CONTINUOUS_VIDEO、CONTINUOUS_PICTURE、EDGE
  • 對焦距離範圍 — 最小和最大對焦距離
  • AF 區域 — 支援的自動對焦區域數量

曝光控制​

檢查：

  • AE 模式 — AUTO、ON、OFF
  • 可用 AE 模式 — 支援哪些曝光模式
  • 曝光範圍 — 最小和最大曝光時間
  • ISO 範圍 — 支援的 ISO 值

換你試試​

現在換您來探索。回答有關您手機的這些問題：

  1. 您的手機有多少個相機？
  2. 它們支援什麼硬體等級？
  3. 哪個相機支援 RAW？
  4. 可用的最高解析度是多少？
  5. 有任何相機支援 4K 錄影嗎？
  6. 最大變焦倍率是多少？
  7. 您的手機有望遠或超廣角相機嗎？

為什麼這很重要​

您可能想知道為什麼我們在撰寫程式碼之前先探索。原因如下：

  1. 每支手機都不同 — 在某個裝置上有效的方法可能在另一個裝置上無效
  2. Camera2 需要適應 — 好的 Camera2 應用程式會查詢功能，而不是假設它們
  3. 理解建立直覺 — 當您看到真實數據時，抽象概念變得具體

當我們開始撰寫程式碼時，您已經知道對您的裝置有什麼期待。

與朋友比較​

如果您有使用不同手機的朋友，比較你們的發現：

  • 旗艦手機是否有更好的硬體等級？
  • 平價手機是否缺少 RAW 支援？
  • 相機數量有什麼差異？

這有助於您了解 Android 相機生態系。

常見發現​

以下是人們常發現的一些事情：

  • 旗艦手機通常具有 FULL 或 LEVEL_3 硬體等級
  • 平價手機通常具有 LIMITED 或 LEGACY 硬體等級
  • 大多數手機支援 JPEG 拍攝
  • RAW 支援仍然不普遍
  • 多鏡頭相機是現代手機的標準配備
  • 前置相機通常解析度低於後置相機

下一章​

既然您已經探索了手機的相機，就可以開始撰寫程式碼了！在下一章中，我們將介紹第一個 Camera2 類別：CameraManager。

CameraManager 是 Camera2 API 的進入點。它讓您可以：

  • 列舉可用的相機
  • 取得相機特性
  • 開啟相機

讓我們開始吧！

總結​

探索手機的相機是了解 Camera2 能做什麼的最佳方式。Android Camera Parameters 透過有組織地顯示所有相機功能，讓這件事變得簡單。

需要留意的重點：

  • 相機 ID 及其角色
  • 硬體等級（LEGACY、LIMITED、FULL、LEVEL_3）
  • 解析度選項
  • RAW 支援
  • 閃光燈和變焦功能
  • 對焦和曝光控制

這種實作探索為撰寫 Camera2 應用程式奠定了基礎。
